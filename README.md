## วิธีอัปเดต
1. ดาวน์โหลดไฟล์ .zip จากตารางด้านบน (เปิดไฟล์แล้วกด "Download raw file")
2. ตรวจว่าไฟล์ไม่เสีย (ไม่บังคับ): `sha256sum -c SHA256SUMS` ต้องขึ้น `OK`
3. เข้าเว็บด้วยบัญชีผู้ดูแล → เมนู "อัปเดตระบบ" → ลากไฟล์ .zip มาวาง → ตรวจเวอร์ชันที่แสดง → ใส่รหัสผ่านอีกครั้ง แล้วกด "ติดตั้งและรีสตาร์ต"
4. ระบบรีสตาร์ตเองภายในไม่กี่วินาที ถ้าเวอร์ชันใหม่เปิดไม่ขึ้นจะย้อนกลับเวอร์ชันเดิมให้อัตโนมัติ

## ข้อควรรู้
- หน้าอัปเดตรับเฉพาะเวอร์ชันที่ใหม่กว่าที่ติดตั้งอยู่
- แพ็กเกจในนี้ **ยังไม่ได้เซ็น** หน้าอัปเดตจะเตือนว่าตรวจไม่ได้ว่าใครสร้าง (ติดตั้งได้ตามปกติ): ถ้าเซิร์ฟเวอร์ตั้ง `UPDATE_PUBLIC_KEY` ไว้ จะไม่รับ ต้องสร้างแพ็กเกจเองแล้วเซ็นด้วย `bun run package --sign <ไฟล์ private key>` (สร้างคู่กุญแจครั้งแรกด้วย `bun run package --gen-key <โฟลเดอร์>`)
- การอัปเดตผ่านเว็บเปลี่ยนตัวแอป แต่ launcher (ตัวคุมการรีสตาร์ต) ยังเป็นตัวเดิมจนกว่าจะ rebuild Docker (`docker compose up -d --build`) ซึ่งแนะนำให้ทำหนึ่งครั้งสำหรับ 1.2.0
- สร้างแพ็กเกจเองจากโค้ด: `bun run package` (ไฟล์จะอยู่ใน `dist-update/`) — แก้ `version` ใน package.json ให้ใหม่กว่าก่อนทุกครั้ง
