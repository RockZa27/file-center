# ตั้งค่าระบบ (ตัวแปรสภาพแวดล้อม)

[← กลับหน้าแรก](../README.md) · [ติดตั้ง](install.md) · [คู่มือผู้ดูแล](admin-guide.md)

หน้านี้รวม **ทุกตัวแปรที่โค้ดอ่าน** จัดเป็นหมวด ตัวแปรส่วนใหญ่มีค่าเริ่มต้นที่ใช้ได้เลย ตั้งเฉพาะที่ต้องการเปลี่ยน

## ลำดับความสำคัญของค่า

ตั้งแต่ 1.13 ผู้ดูแลแก้ค่าที่ใช้บ่อยได้ในหน้าเว็บ (**ระบบ → ตั้งค่า**) โดยไม่ต้องแก้ไฟล์หรือรีสตาร์ต ลำดับคือ **ค่าในหน้าเว็บ (`settings.json`) → ค่าใน `.env` → ค่าเริ่มต้น** ค่าที่ยังไม่เคยบันทึกในหน้าเว็บใช้ค่าใน `.env` เหมือนเดิม จึงไม่มีอะไรเปลี่ยนสำหรับระบบที่ไม่เคยเปิดหน้าตั้งค่า และเมื่อค่าในเว็บมีอยู่แล้ว การแก้ `.env` ภายหลังจะ **ไม่มีผล** จนกว่าจะล้างค่าในเว็บให้กลับไปใช้ค่าจาก `.env` ตัวแปรที่ทำได้ในหน้าเว็บมีป้าย **ตั้งในหน้าเว็บได้** ในตารางด้านล่าง (ค่าที่ตั้งได้เฉพาะในเว็บ เช่น บังคับ 2FA และโควตาเริ่มต้น ดู [คู่มือผู้ดูแล](admin-guide.md#ตั้งค่าระบบในหน้าเว็บ)) ส่วนตัวแปรที่ไม่มีป้าย เช่นพอร์ต ที่เก็บข้อมูล และ HTTPS ต้องตั้งใน `.env` เท่านั้น

## วิธีตั้งค่า

1. คัดลอกไฟล์ตัวอย่าง: `cp .env.example .env`
2. เปิด `.env` แล้วใส่บรรทัด `ชื่อ=ค่า` (บรรทัดที่ขึ้นต้นด้วย `#` คือคอมเมนต์)
3. เริ่มระบบใหม่ให้อ่านค่าใหม่
   - Docker: `docker compose up -d`
   - Bun: หยุดแล้วเริ่มใหม่ด้วย `bun start`

ข้อควรรู้

- **Docker:** `docker-compose.yml` ส่งทุกบรรทัดใน `.env` เข้าคอนเทนเนอร์ (`env_file`) ตัวแปรที่ไม่ได้อยู่ในไฟล์ตัวอย่างก็ใส่ใน `.env` ได้ ยกเว้น `TUNNEL_TOKEN` ที่ compose ตั้งให้ตัวแอปเห็นเป็นค่าว่างโดยเจตนา
- **ขนาด** ทุกตัวเป็น **ไบต์** (เช่น 1 GB = `1073741824`)
- **ตัวเลข** ถ้าใส่ค่าที่ไม่ใช่ตัวเลข หรือเว้นว่าง ระบบใช้ค่าเริ่มต้น
- **ตัวเลือกเปิด/ปิด** ค่าที่ระบบรู้จักต่างกันตามตัวแปร ดูในตาราง (`true` / `false` / `on` / `off`)
- ค่าที่ระบบตรวจแล้วใช้ไม่ได้ (เช่น URL ผิดรูปแบบ) ระบบยังเปิดได้ แต่ปิดฟีเจอร์นั้นและเตือนใน log ตอนเริ่ม
- **รหัสผ่าน โทเคน และกุญแจ** ใน `.env` เป็นความลับ ห้ามแชร์หรือ commit (`.env` อยู่ใน `.gitignore` แล้ว)

## ที่อยู่ เครือข่าย และ HTTPS

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | `3000` | พอร์ตที่แอปเปิดรับ ใน Docker คือ **พอร์ตฝั่งเครื่อง host** (ในคอนเทนเนอร์ใช้ 3000 เสมอ) |
| `HOST` | `0.0.0.0` | ที่อยู่ที่แอปเปิดรับ (ในคอนเทนเนอร์ใช้ค่าเริ่มต้น ไม่ต้องแก้ ใช้ `BIND_ADDRESS` คุมว่าเครื่องไหนเข้าได้) |
| `BIND_ADDRESS` | `127.0.0.1` | (Docker) เครื่องไหนเข้าพอร์ตตรงได้ `127.0.0.1` = เครื่อง server เท่านั้น `0.0.0.0` = ทุกเครื่องในวง LAN |
| `TRUST_PROXY` | `false` | ที่มาของ IP ผู้ใช้ `false` = ไม่มี proxy · `cloudflare` = หัว `CF-Connecting-IP` (Cloudflare Tunnel) · `true` = ค่าสุดท้ายของ `X-Forwarded-For` (nginx/Caddy ของคุณเอง) มีผลกับการล็อกรหัสผิดและประวัติการใช้งาน |
| `SECURE_COOKIE` | `false` | `true` เมื่อใช้ผ่าน HTTPS: cookie เป็นแบบ Secure และทุกคำตอบมีหัว `Strict-Transport-Security` |
| `PUBLIC_URL` | ว่าง | ที่อยู่ที่คนเปิด File Center เช่น `https://files.example.com` ใช้สร้างลิงก์ในอีเมล (ต้องตั้งเมื่อเปิดอีเมล) ไม่เอามาจากหัว `Host` ของคำขอ |

## Docker และ Compose

ตัวแปรกลุ่มนี้ `docker-compose.yml` กับ entrypoint อ่าน ไม่ใช่ตัวแอปโดยตรง

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `COMPOSE_PROFILES` | ว่าง (ใน `.env.example` ตั้ง `tunnel`) | เลือกบริการเสริม `tunnel` = Cloudflare Tunnel · `office` = ONLYOFFICE · หลายค่าคั่นด้วย `,` เช่น `tunnel,office` |
| `TUNNEL_TOKEN` | ว่าง | โทเคนของ Cloudflare Tunnel (ใช้กับบริการ `cloudflared` เท่านั้น) ใครได้ไปก็ต่อเข้าโดเมนนี้ได้ ห้ามแชร์ |
| `FC_RUN_AS_ROOT` | `false` | `true` = รันแอปเป็น root แบบเดิม ไม่เปลี่ยนเจ้าของ `./data` (ทางหนีไฟ ปกติรันเป็นผู้ใช้ `bun` uid 1000) |
| `FC_DATA_ROOT` | `/data` | โฟลเดอร์ที่ entrypoint ตรวจ/เปลี่ยนเจ้าของ ไม่ต้องแก้ ยกเว้นอิมเมจที่ปรับเอง |
| `FC_MEMORY_LIMIT` | `2g` | หน่วยความจำสูงสุดของคอนเทนเนอร์ `file-center` เกินแล้วแอปถูกฆ่า |
| `FC_PIDS_LIMIT` | `512` | จำนวนโปรเซสสูงสุดของคอนเทนเนอร์ |
| `THUMB_VIDEO` | `true` | (ตอน build) `false` = ไม่ติดตั้ง ffmpeg ในอิมเมจ (เล็กลงราว 350 MB ไม่มีภาพตัวอย่างวิดีโอ) ต้อง `docker compose up -d --build` |
| `OFFICE_PORT` | `8080` | (Docker) พอร์ตของ document server บน `127.0.0.1` |
| `TZ` | เวลาของเครื่อง (ในคอนเทนเนอร์ปกติเป็น UTC) | เขตเวลาของ server มีผลกับเวลาสำรองข้อมูลอัตโนมัติ (`BACKUP_HOUR` และตารางเวลา) เช่น `Asia/Bangkok` ทดสอบกับ Bun แล้ว ไม่ได้ทดสอบในคอนเทนเนอร์ |

ตัวเลือกตอน build (ใช้กับ `docker compose build --build-arg ...` ไม่ใช่ `.env`)

| อาร์กิวเมนต์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `APT_UPGRADE` | `true` | ลงอัปเดตความปลอดภัยของ Debian ตอน build `false` เฉพาะเครื่องที่เข้า mirror ของ Debian ไม่ได้ |
| `THUMB_TOOLS` | `true` | ลงเครื่องมือทำภาพตัวอย่าง (`libvips-tools`, `poppler-utils`, ฟอนต์, และ `ffmpeg` ถ้า `THUMB_VIDEO=true`) `false` = ไม่ลงอะไรเลย เฉพาะเครื่องที่เข้า mirror ไม่ได้ |

## ที่เก็บข้อมูล

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `STORAGE_DIR` | `./storage` (Docker: `/data/storage`) | ที่เก็บไฟล์ที่อัปโหลด |
| `DATA_DIR` | `./data` (Docker: `/data/system`) | ผู้ใช้ ตั้งค่า session log ถังขยะ ไฟล์อัปโหลดที่ยังไม่เสร็จ ดู [ไฟล์ข้อมูลใน DATA_DIR](#ไฟล์ข้อมูลใน-data_dir) |
| `BACKUP_DIR` | โฟลเดอร์ `backups` ข้าง `DATA_DIR` (Docker: `/data/backups`) | ที่เก็บไฟล์สำรอง ควรอยู่คนละดิสก์กับข้อมูล ดู [สำรองข้อมูล](#สำรองข้อมูล) |
| `WEB_DIR` | `web/dist` | โฟลเดอร์หน้าเว็บที่คอมไพล์แล้ว launcher ตั้งให้เองเมื่อรันเวอร์ชันที่อัปเดตจากหน้าเว็บ ไม่ต้องตั้งเอง |

ใน Docker โฟลเดอร์บนเครื่อง host คือ `./data/storage` และ `./data/system` (เมาท์เป็น `/data`)

## บัญชีผู้ดูแลและการเข้าสู่ระบบ

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `ADMIN_PASSWORD` | สุ่ม | รหัสผ่านของ `admin` ตอนสร้างบัญชีครั้งแรก ถ้าเว้นว่างระบบสุ่มให้และแสดงใน `docker compose logs file-center` (บังคับเปลี่ยนเมื่อเข้าสู่ระบบ) ไม่มีผลกับบัญชีที่สร้างแล้ว |
| `SESSION_TTL_HOURS` | `168` (7 วัน) | ผู้ที่ไม่ได้ใช้งานเกินเวลานี้ session หมดอายุ **ตั้งในหน้าเว็บได้ (ระบบ → ตั้งค่า → หมวดความปลอดภัย) — ค่าในเว็บชนะ .env** |
| `LOGIN_MAX_ATTEMPTS` | `5` | ใส่รหัสผ่านผิดได้กี่ครั้ง (นับแยกตาม IP + ชื่อผู้ใช้) ก่อนถูกล็อก **ตั้งในหน้าเว็บได้ (ระบบ → ตั้งค่า → หมวดความปลอดภัย) — ค่าในเว็บชนะ .env** |
| `LOGIN_LOCKOUT_SECONDS` | `60` | ล็อกนานกี่วินาที (ใช้กับรหัส 2FA และรหัสผ่านแอป WebDAV ด้วย) **ตั้งในหน้าเว็บได้ (ระบบ → ตั้งค่า → หมวดความปลอดภัย) — ค่าในเว็บชนะ .env** |

## อัปโหลด ไฟล์ และถังขยะ

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `UPLOAD_MAX_SIZE` | `10737418240` (10 GB) | ขนาดสูงสุดต่อไฟล์ (ไบต์) ใช้กับ WebDAV ด้วย ค่านี้เป็น **เพดาน** ที่ server เริ่มด้วย: ในหน้าเว็บลดได้แต่ตั้งเกินค่านี้ไม่ได้ (ต้องแก้ `.env` แล้วรีสตาร์ต) **ตั้งในหน้าเว็บได้ (ระบบ → ตั้งค่า → หมวดไฟล์และพื้นที่) — ค่าในเว็บชนะ .env** |
| `GUEST_UPLOAD_DAILY_BYTES` | `1073741824` (1 GB) | ขนาดรวมที่ผู้เยี่ยมชมทุกคนอัปโหลดได้รวมกันต่อวัน (เมื่อเปิดสิทธิ์อัปโหลดให้ผู้เยี่ยมชม) `0` = อัปโหลดไม่ได้เลย |
| `MIN_FREE_SPACE` | `2147483648` (2 GB) | ปฏิเสธอัปโหลด คัดลอก บีบอัด และแตก zip เมื่อดิสก์จะเหลือว่างน้อยกว่านี้ (ใช้ตรวจก่อนสำรองข้อมูลด้วย) |
| `UPLOAD_REQUEST_MAX_FILE` | `1073741824` (1 GB) | ขนาดต่อไฟล์ของลิงก์รับไฟล์ที่ผู้สร้างไม่ได้กำหนดข้อจำกัดเอง |
| `UPLOAD_REQUEST_MAX_TOTAL` | `5368709120` (5 GB) | ขนาดรวมต่อลิงก์ ของลิงก์รับไฟล์ที่ไม่ได้กำหนดข้อจำกัดเอง |
| `SHARE_MAX_DAYS` | `30` | อายุสูงสุดของลิงก์แชร์ (วัน) ลิงก์เลือกอายุได้ 1, 7 หรือ 30 วัน เท่าที่ไม่เกินค่านี้ **ตั้งในหน้าเว็บได้ (ระบบ → ตั้งค่า → หมวดแชร์) — ค่าในเว็บชนะ .env** |
| `TRASH_RETENTION_DAYS` | `30` | เก็บของในถังขยะกี่วัน **ตั้งในหน้าเว็บได้ (ระบบ → ตั้งค่า → หมวดไฟล์และพื้นที่) — ค่าในเว็บชนะ .env** |
| `VERSIONS_KEEP` | `10` | เก็บเนื้อหาเดิมของไฟล์ไว้ทุกครั้งที่บันทึกทับ (แก้ข้อความ ONLYOFFICE กู้คืนฉบับเก่า WebDAV) กี่ฉบับต่อไฟล์ `0` = ไม่เก็บ **ตั้งในหน้าเว็บได้ (ระบบ → ตั้งค่า → หมวดไฟล์และพื้นที่) — ค่าในเว็บชนะ .env** |
| `VERSIONS_DAYS` | `30` | เก็บเวอร์ชันเก่านานกี่วัน `0` = ไม่หมดอายุตามวัน (หลุดเมื่อเกินจำนวน) ฉบับเก่านับรวมในโควตาของเจ้าของโฟลเดอร์ ไม่อยู่ในไฟล์สำรอง **ตั้งในหน้าเว็บได้ (ระบบ → ตั้งค่า → หมวดไฟล์และพื้นที่) — ค่าในเว็บชนะ .env** |

## สำรองข้อมูล

ค่าที่ตั้งในหน้า **ระบบ → สำรองข้อมูล** ของเว็บใช้แทนสามตัวแปรท้ายตาราง (`BACKUP_KEEP`, `BACKUP_HOUR`, `BACKUP_INCLUDE_FILES`) ตัวแปรเป็นแค่ค่าเริ่มต้นเมื่อยังไม่เคยตั้งในหน้าเว็บ

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `BACKUP_DIR` | โฟลเดอร์ `backups` ข้าง `DATA_DIR` (Docker: `/data/backups`) | ที่เก็บไฟล์สำรอง ถ้าอยู่ดิสก์เดียวกับข้อมูล ดิสก์เสียแล้วไฟล์สำรองหายด้วย |
| `BACKUP_KEEP` | `7` | เก็บไฟล์สำรองล่าสุดกี่ไฟล์ (อย่างน้อย 1) ถ้ารวมไฟล์และยังไม่เคยตั้งในหน้าเว็บ เก็บ 2 ไฟล์ |
| `BACKUP_HOUR` | `3` | สำรองอัตโนมัติทุกวันชั่วโมงไหน (0-23 ตามเวลาเครื่อง) `off` = ปิดการสำรองอัตโนมัติ |
| `BACKUP_INCLUDE_FILES` | `false` | `true` = รวมไฟล์ที่อัปโหลด (`storage`) ไว้ในไฟล์สำรองด้วย (อาจใหญ่มาก) |

ค่าปรับจูนที่ค่าเริ่มต้นเหมาะกับการใช้งานทั่วไปแล้ว แก้เมื่อมีเหตุผลเฉพาะ (เครื่องช้า ดิสก์เล็ก ไฟล์แปลก) เท่านั้น ทุกตัวตั้งใน `.env` อย่างเดียว ไม่มีในหน้าเว็บ

### ปรับจูนอัปโหลด การล็อก และ log

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `UPLOAD_CHUNK_SIZE` | `8388608` (8 MB) | ขนาดชิ้นส่วนที่หน้าเว็บส่งทีละชิ้น ห้ามเกิน 100 MB เมื่อใช้ Cloudflare |
| `UPLOAD_SIMULTANEOUS` | `6` | จำนวนชิ้นที่หน้าเว็บส่งพร้อมกัน |
| `UPLOAD_STALE_HOURS` | `3` | ลบอัปโหลดที่ไม่เสร็จและไม่มีชิ้นใหม่เข้ามาเกินกี่ชั่วโมง |
| `UPLOAD_REQUEST_IDLE_MINUTES` | `15` | งานอัปโหลดของลิงก์รับไฟล์ที่ประกาศแล้วแต่ไม่มีชิ้นใหม่นานเท่านี้ จะคืนที่ว่างของลิงก์และถูกลบ (ไม่รอ `UPLOAD_STALE_HOURS`) |

| `LOGIN_ADDRESS_MAX_ATTEMPTS` | `30` | ล็อกแบบกว้าง: รหัสผ่านผิดของ **IP เดียว** กับทุกชื่อผู้ใช้รวมกัน |
| `LOGIN_WIDE_WINDOW_MINUTES` | `15` | ช่วงเวลาที่นับสองข้อบน และเป็นเวลารอเมื่อถูกล็อก (นาที) |
| `LOG_MAX_BYTES` | `10485760` (10 MB) | หมุนไฟล์ `logs/system.log` (และ `access.log`, `launcher.log`) เมื่อใหญ่ถึงขนาดนี้ |
| `LOG_MAX_FILES` | `5` | เก็บกี่ไฟล์ (นับรวมไฟล์ปัจจุบัน อย่างน้อย 2) |

### ปรับจูนไฟล์ ค้นหา และ WebDAV

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `THUMB_CACHE_MAX_MB` | `1024` | ขนาดสูงสุดของแคชภาพตัวอย่าง (`DATA_DIR/thumbs`) เป็น MB เกินแล้วลบอันที่ไม่ได้ใช้นานที่สุดก่อน (ตรวจทุกชั่วโมง) ไม่อยู่ในไฟล์สำรอง |
| `UNZIP_MAX_BYTES` | `21474836480` (20 GB) | ขนาดรวมสูงสุดที่แตกจาก zip หนึ่งไฟล์ได้ (กัน zip bomb) |
| `UNZIP_MAX_FILES` | `50000` | จำนวนไฟล์สูงสุดที่แตกจาก zip หนึ่งไฟล์ได้ |
| `ZIP_LEGACY_ENCODING` | `cp874` | encoding ของชื่อไฟล์ใน zip ที่ไม่ได้บอกว่าเป็น UTF-8 (zip จาก Windows รุ่นเก่า) `cp874` = ภาษาไทย หรือ `cp437`, `cp932`, `cp936`, `cp949`, `cp950`, `cp125x` |
| `WEBDAV_MAX_ITEMS` | `100000` | โฟลเดอร์ที่มีรายการตั้งแต่นี้ขึ้นไป `PROPFIND` แบบ `Depth: 1` ตอบ 507 |
| `SEARCH_RESCAN_MINUTES` | `30` | สแกนดัชนี (`DATA_DIR/search.db`) ใหม่จากดิสก์ทุกกี่นาที `0` = สแกนตอนเริ่มครั้งเดียว |

### อัปเดตระบบ (ขั้นสูง)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `UPDATE_MAX_SIZE` | `209715200` (200 MB) | ขนาดสูงสุดของแพ็กเกจอัปเดต |
| `FC_HEALTH_TIMEOUT_MS` | `40000` | launcher รอให้เวอร์ชันที่เพิ่งติดตั้งตอบ `/api/health` นานเท่าไร (มิลลิวินาที) ก่อนย้อนกลับ เครื่องช้าหรือข้อมูลมากให้เพิ่ม |
| `FC_STABLE_MS` | `8000` | เวอร์ชันใหม่ต้องอยู่รอดหลังตอบครั้งแรกนานเท่าไร (มิลลิวินาที) จึงนับว่าติดตั้งสำเร็จ |

`FC_HEALTH_TIMEOUT_MS` กับ `FC_STABLE_MS` ใส่ใน `.env` ได้ (Docker ส่งเข้าคอนเทนเนอร์ให้) launcher อ่านตอนเริ่มระบบ

### สำหรับนักพัฒนาและการทดสอบเท่านั้น

> **คำเตือน:** `UPDATE_ALLOW_UNSIGNED=true` ปิดการตรวจลายเซ็นของแพ็กเกจอัปเดต ผู้ที่ได้ session และรหัสผ่านของ admin (หรือควบคุมแหล่งอัปเดตได้) จะติดตั้งโค้ดอะไรก็ได้บนเครื่องนี้ **ห้ามเปิดบนระบบจริง** ระบบเตือนเป็นระดับ critical ที่ `GET /api/admin/config-warnings` ดู [คู่มือผู้ดูแล](admin-guide.md#คำเตือนการตั้งค่าและวิธีแก้)

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `UPDATE_PUBLIC_KEY` | ว่าง (ใช้กุญแจของ File Center ที่ฝังมา) | public key จาก `bun run package --gen-key` ใช้ตรวจลายเซ็นแพ็กเกจ **แทน** กุญแจที่ฝังมา สำหรับคนที่สร้างแพ็กเกจเอง ค่าผิดรูปแบบ = ไม่รับแพ็กเกจใดเลยจนกว่าจะแก้ |
| `UPDATE_ALLOW_UNSIGNED` | `false` | `true` = รับแพ็กเกจที่ไม่เซ็นด้วย (เสี่ยง: ผู้ที่ได้ session และรหัสผ่านของ admin ติดตั้งโค้ดของตัวเองได้) ระบบเตือนในหน้าภาพรวมและหน้าอัปเดต |
| `LINE_API_BASE` | ว่าง | **ไว้ทดสอบเท่านั้น** ชี้ไปที่เซิร์ฟเวอร์จำลองบนเครื่องนี้ (`http://127.0.0.1:<พอร์ต>`) ค่าอื่นถูกเมินและใช้ `https://api.line.me` เสมอ ไม่ต้องตั้งในการใช้งานจริง |

ตัวแปร `FC_*` ที่เหลือ (`FC_SUPERVISED`, `FC_VERSION`, `FC_RELEASE`, `FC_BUILTIN_VERSION`) launcher ตั้งเอง ดู [ตัวแปรที่ระบบตั้งเอง](#ตัวแปรที่ระบบตั้งเอง) ส่วน `FC_RUN_AS_ROOT`, `FC_DATA_ROOT`, `FC_MEMORY_LIMIT`, `FC_PIDS_LIMIT` ของ Docker อยู่ที่ [Docker และ Compose](#docker-และ-compose)
