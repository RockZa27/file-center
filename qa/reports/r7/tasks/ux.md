Compute TOTP codes in your script from the secret the page shows (RFC 6238: HMAC-SHA1 over the 8-byte big-endian step = floor(now/30), dynamic truncation, 6 digits; the secret is base32). A code is good once: wait for the next 30 s step before using a second code.

2. two-step-login: sign out; sign in with password → second step asks for the code; a wrong code shows an error; the right code signs in; sign out and sign in with a backup code via "use a backup code"; that same backup code a second time is refused. Wrong codes until locked: the page shows the lockout with a wait.
3. devices: sign in from a second browser context; the first context's device list shows two devices (this one marked); sign out the other one → the second context is signed out on its next action; "sign out all other devices" works too.
