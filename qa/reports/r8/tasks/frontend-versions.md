Web pages for file versions, favorites/recent, copy/move between spaces and the 2FA date (the server side is on the base: read src/routes/versions.ts, src/versions.ts, src/routes/me.ts, src/favorites.ts, the transfer code in src/routes/files.ts and tests/versions.test.ts for the exact shapes and codes).

1. Versions: in the file browser's item menu (and the preview/editor toolbar for text files), "Previous versions" / "เวอร์ชันก่อนหน้า" opens a dialog listing `GET /api/versions` (saved time as relative + exact on hover, size, who, reason edit/office/restore), each with Download, Restore (confirm; sends the current mtime as `expectedMtime`, handles 409 by offering to reload) and Delete (confirm). Only shown where the user has `read`; Restore/Delete only with `write`. After a restore an open editor/preview reloads.
2. Favorites and recent: a star toggle on each row (and in the preview header); a "Favorites" / "Recent" entry in the side menu opening a page with two tabs listing `GET /api/me/favorites` and `/api/me/recent` (name, folder path, space, time for recent); clicking opens the file's folder with the file selected (or the preview); unstar from the list. Signed-in users only.
3. Copy/move dialog: a space picker (Home / Public — only spaces where the user has `write`+`upload`) above the folder tree; sends `destSpace`; shows per-item failures (e.g. quota) as today.
4. Security tab: show "On since <date>" from `twoFactorSince`.
5. Every new string in th and en in web/src/i18n.js.
6. Browser check (1200 px and 375 px, th and en): edit a .md three times, open Previous versions, restore the first one, the editor shows it and a new version of the overwritten text exists; a read-only user sees the list without restore/delete; star two files, see them in Favorites, unstar one; open a file and see it in Recent; copy a file from Public into Home with the space picker; the 2FA "since" date.
