   - Built in the background at start (both the storage root and the public folder, not following links, same rules as `searchTree` in src/fsx.ts) without blocking requests (batches, yields); re-scanned every `SEARCH_RESCAN_MINUTES` (default 30) with the single-run pattern of `recountStorage` in src/stats.ts.

Results are ONLY under the caller's space root and start path (prefix check on whole path segments, as `within` in src/fsx.ts) and only for spaces they can `read`. Same response shape plus `indexed`.
