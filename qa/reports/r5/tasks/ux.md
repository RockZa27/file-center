Start the app with ACCESS_LOG=true, your own PORT/STORAGE_DIR/DATA_DIR. Use a browser context whose `locale` is the OTHER language from the page.
1. share-file: as a normal user with `share` (give it on the users page as admin first — check the checkbox exists and stays after saving), share a file with 7 days and no password from the row menu; copy the link; open it in a new context with no session: name, size, download gives the right bytes. The link appears on "Shared links" with downloads = 1.
2. share-folder-password: share a folder (with a subfolder and a long Thai file name, 80+ letters) with a password and a limit of 2 downloads. Visitor: wrong password shows an error in the page language; after 5 wrong tries a lockout message; with the right password: browse into the subfolder and back, download one file and the folder as zip; after the limit the link says "not found or expired". The owner sees it as used up.
3. share-revoke-expire: revoke a link from "Shared links": the visitor's open page fails on its next action and a reload shows "not found or expired". A made-up link (`/s/` + 43 random characters) shows the same message. Admin: the all-links switch shows other users' links with the owner.
4. update-check: run a tiny HTTP server serving `latest.json` + a package built with `bun scripts/package.ts --version <newer> --out <dir>` (sha256 and size from the file) and start the app with `UPDATE_SOURCE=http://127.0.0.1:<port>`. On the update page: "check for updates" shows the new version and the unsigned warning; "download and prepare" leads to the normal password step; install and the page comes back on the new version. Then change latest.json's sha256: a clear checksum error, nothing staged.
5. language-followups: switch the page to English: dashboard backup status, the public page welcome texts (empty in settings) and the update result are English without reload; settings shows the standard texts as placeholders.
6. downloads-and-missing-folder: on logs/activity/backup middle-click (or read the href of) a download button: it is a real link; a normal click still downloads. Open `/files?path=/no-such-folder`: a "folder not found" message, then the top folder.
7. mobile: at 375 x 812, the share modal, "Shared links" and the public share page (with the long Thai name) have no horizontal scrolling.
